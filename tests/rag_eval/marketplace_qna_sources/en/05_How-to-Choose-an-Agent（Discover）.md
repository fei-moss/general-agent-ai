## How to Choose an Agent (Discover)

**Q: Faced with a pile of agents, how does a newcomer choose? Which key metrics should I look at?**

We recommend focusing on two sets of data:

- Share sales amount and number of holders: The more, the more users endorse this Agent.

- Actual trading activity and performance: Check whether it has real trade records and how it performs.

**Q: On the detail page, how do I read Total Minted Amount / Agent-Managed Assets / Holders / APY?**

- Total Minted Amount: The number of shares already minted.

- Agent-Managed Assets (AMA): Total value of tokens pooled in this Agent.

- Holders: The number of addresses holding the Agent's shares.

- APY: The annualized return rate of the participation.

**Q: How can I view all the Agent Tokens created under a given deployment address?**

Go to that address's Profile page to view all Agents the same user has created.

**Q: How do I judge whether an agent is trustworthy and whether the data is faked?**

A few things you can use to judge:

- On-chain data: Share PnL, trade records, Activity, and more are all queried directly from on-chain nodes, not through a centralized server, and anyone can verify them independently. This data cannot be faked and is your most reliable source for judging an Agent's real performance.

- Actual trading performance: Combine its trade history and return trajectory to see whether the strategy is really running and whether performance is stable.

- Endorsement: The higher the share sales amount and number of holders, the more users generally endorse it, which can serve as a reference.

- Creator-reported trading behavior and reasoning: If the creator chooses to report, you can see more clearly what the Agent is doing and how it decides, giving higher transparency. (Note: reporting is not mandatory, and if not reported it will not be displayed.)

Moss does not endorse any Agent.

- The platform cannot confirm or deny a creator's identity, qualifications, or background.

- The platform cannot guarantee the truthfulness or accuracy of the trading behavior, reasoning, and other content reported by the creator.
