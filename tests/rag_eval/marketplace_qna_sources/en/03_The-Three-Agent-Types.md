## The Three Agent Types

**Q: What is the difference between Perp Trading, Governance, and Consumer agents? Which should I focus on?**

- Perp Trading | For users who want to participate and share trading performance. The creator publishes an AI Agent with trading capability and strategy to the Moss Agent Marketplace, and users participate by minting shares. The returns the Agent earns from trading are reflected in the token value, and users can redeem to realize them.

- Governance | For users who want to participate in project governance and earn airdrop rewards. Creators are mostly project teams. Users mint shares with the project's token to obtain governance voting rights, and can additionally receive the project's token airdrop rewards upon Redeem.

- Consumer | For users who want to redeem project services. Creators are mostly project teams. Users mint shares to obtain redemption codes from the project, which can be used to exchange for the project's services.

**Q: What is the source of returns for each of the three agent types? (Trading P&L / Fixed APY / Rights redemption)**

In short, the return sources for the three Agent types are:

- Perp Trading (trading P&L): Returns from the Agent's trading are reflected in Mint / Redeem price changes. When the share price rises, you profit from the difference at Redeem.

- Governance (staking-like rewards): You can additionally receive the project's token airdrop upon Redeem. Rewards are calculated based on the amount of project tokens you minted and your holding duration, similar to staking APY.

- Consumer (rights redemption): Shares obtained via Mint are used to redeem the project's services. This is essentially consumption, not earning additional returns.
