## Moss Agent Tool

**Q: Will the historical data of older agents (trade records, returns, runtime) be fully preserved?**

Yes, fully preserved. Historical data is not adjusted in any way and is migrated intact to the new page.

**Q: Can I run the Tool myself for a while to validate the strategy before deciding whether to Tokenize and go live on Marketplace?**

Absolutely. The timing of Tokenizing is entirely up to you, with no additional restrictions from the platform. You can let the Agent run for a while, observe how the strategy performs, and Tokenize it when you feel ready.

**Q: If I Tokenize an existing Agent Tool-created Agent, does it change its original strategy, performance, or history?**

No. Tokenizing and the trading strategy are two independent matters. Whether or not you Tokenize, it does not change the Agent's own trading strategy, and its existing performance and historical data remain unchanged.

**Q: What conditions must an agent built with natural language meet before it can be Tokenized and go live on Marketplace (for example, running long enough, or having a real track record)?**

There are no prerequisites. Whether and when to Tokenize is entirely up to you. The platform sets no thresholds such as a minimum runtime or required track record.

**Q: Are there limits on creating Agents with Agent Tool? How many can one person create at most?**

One account can create up to 6 Agents, regardless of Agent type. The six slots are shared across all types.

**Q: Can only live agents go to the Marketplace and be minted by others? Can backtested ones be listed?**

Only live Agents can be listed on the Marketplace. Backtests (simulations) cannot be listed. In other words, any Agent that others can Mint is a real, live-running Agent.

**Q: Walking through the full path from "building an agent with AI" to "Tokenizing your Agent" to "others minting shares," what does it look like? How do the entry points connect?**

The full path has three steps: (entry URLs and matching Gitbook tutorials to be added here later)

1. Build the Agent: Use Moss Agent Tool in self-hosted mode (or another AI trading platform) to build a trading Agent, and generate a Hyperliquid trading address for it.

2. Tokenize your Agent: On the Moss protocol market, use the Tokenize Agent configuration flow to publish and open the Agent for Minting.

3. User participation: Once the Agent is listed on the Marketplace, other users can view, Mint, and Redeem it there.
