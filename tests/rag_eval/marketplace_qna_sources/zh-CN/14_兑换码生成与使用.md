## 兑换码生成与使用

本篇只说明用户主动发起的 Consumer Agent 换码流程。每码门槛、价值和有效期读取当前 Agent 页面或 typed context；未经批准的兑换码找回、转让和有效期问题保持待产品 owner 输入。

**Q：怎么把份额换成兑换码？**

打开当前 Consumer Agent 并点击“去兑换”，选择数量后确认；达到配置门槛时，份额被消耗并生成兑换码。

**Q：多少份额可以换一个码？**

每码所需份额不是平台统一常量，必须读取当前 Agent 配置。

**Q：兑换成功后，使用掉的份额会怎样？**

兑换会消耗对应份额；这些份额也不能恢复或再用于 Refund。

**Q：换码时，如果只想换一部分权益，剩余 Consumer 份额会怎样？**

没有参与本次兑换的份额仍由用户持有，之后可发起 Consumer Agent Refund。

**Q：生成兑换码后怎么去消费？**

成功弹窗提供“去消费”跳转按钮，当前目标入口由 Agent 页面提供。

**Q：份额已扣但兑换码没有生成怎么办？**

系统应记录异常并重试；仍未恢复时，通过当前 Agent 页面显示的支持方式提交该次操作记录。

**Q：持有时间到了会自动兑换吗？**

Consumer Agent 没有自动兑换；用户必须主动发起并确认换码。

**Q：换码前要去哪里查看门槛、码的价值和有效期？**

这些事实必须读取当前 Agent 页面或 typed context；未提供有效期时保持待定，不能编造期限。
