## 六、发起／Tokenize

**Q：发起一个 agent 并在链上汇集资金具体是什么意思？我募到的是谁的钱、用来干嘛？**

创建者把有交易能力和策略的 AI Agent 发布到市场，用户通过 Mint 份额投资它。募集到的资金用于 Agent 的真实交易，Agent 交易赚到的收益，通过 Mint / Redeem 的价格变动分给持有人。

**Q：创建者怎么赚钱？Management Fee 和 Profit Share 分别是什么、能设多少、什么时候到账？**

创建者的收益主要来源于 **Agent 费用机制**，当前主要有两类：

Management Fee（管理费，实际就是 Mint / Redeem Fee）

- 用户 Mint 进场时，按配置收取 Mint Fee；用户 Redeem 退场时，按配置收取 Redeem Fee。

- 具体费率能设多少，以创建时的 Agent 配置和链上合约限制为准，各 Agent 不一定相同。

Profit Share（收益分成）

- Agent 通过 executor 实际交易赚钱后，收益进入合约，创建者可按合约约定分享一部分收益。

- 是否支持、比例多少、何时结算，都取决于具体 Agent 设置时的合约规则。

收益到账：

- Mint Fee、Redeem Fee、以及 Agent 盈利后份额单价变动带来的收益等费用和分成**不是平台人工打款**，由链上合约和结算逻辑决定。

- 具体何时可领、是否自动结算、是否需要主动 claim，创建者可以参照 Agent 链上合约实现以及 Agent 管理页面。

**Q：我发起 agent 需要自己出本金吗？还是全靠别人 mint 进来的钱？**

**不一定要自己出全部本金。** Agent 的主要资金来自参与者 Mint 进来的 Accept Token，创建者不需要自己把本金填满。

但作为创建者，你至少要承担这些基础成本：

- Gas：部署合约和链上操作的手续费。

- 配置成本：创建 Agent 时填信息、配参数、绑定 executor / trading wallet。

两点补充说明：

- 如果没人 Mint，Agent 可管理的资金就很少，策略可能跑不起来或规模有限。

- 某些模板未来可能要求初始资金或最低启动规模，以模板规则为准。

简单来讲，你不必自己出全部本金，主要资金靠参与者 Mint；但部署和配置的基础成本要自己承担，是否需要初始资金则看具体模板要求。

**Q：别人 mint 进来的资金，我作为创建者能动吗？**

不能。这些资金进入的是代码托管的 Agent 合约，而不是创建者的个人钱包，因此不能像余额一样随意转走。 Agent 运行中的角色分工是：

- 投资者：Mint 资金，获得份额。

- Agent 合约：负责份额记账、Mint / Redeem、净值计算和资金约束。

- 创建者 / Owner：负责管理 Agent（配置 executor、暂停操作、维护等）。

- Executor：负责实际执行交易或策略。

因此，创建者的身份本质是"管理员"，并不能随意支配资金，资金能否用于交易、能否转入外部协议、能否提费、能否暂停，都由合约规则和 executor 权限决定。

**Q: 我的策略/ prompt 会被公开吗？会不会被别人抄走？**

不会完整公开。 页面只展示你主动填写的公开描述，以及你选择上报的交易日志 / 活动记录。透明度由你自己把控：

- 完全不公开策略细节 → 参与者只能看链上数据，信任成本高。

- 适度上报交易日志 / 策略解释 → 参与者更容易理解 Agent，信任度更高。

- 公开完整 prompt / 核心策略 → 最透明，但也可能被复制。

建议你做平衡：可以公开策略方向、风控逻辑、交易记录、复盘说明；不要公开私钥、API Key、完整核心 prompt、完整系统细节。日志上报不是必须的，但能帮你建立参与者信任。

**Q: agent 上架后表现不好，我能下架/ 停掉/ 改策略吗？对持有人有什么影响？**

Agent的交易策略创建者可以随时修改，这个本质上和协议市场平台无关。目前 Moss Agent Marketplace 暂时不支持下架 Agent。

**Q：模板/链选好之后还能修改吗？**

可以。在 Agent 未创建完成前，都支持重新选择或修改。

**Q：Tokenize 汇集资金之后，我还能像在 Tool 里那样随时改策略/ 调参数吗？改了对已经 mint 的 holders 有什么影响？**

Agent 的交易策略你可以随时修改，这本质上不会影响 Moss Agent Marketplace 上线的 Agent。

**Q：上架汇集资金后，我这个创建者对资金还有多大控制权？哪些能动、哪些动不了？**

别人 Mint 进来的资金进入的是 Agent 合约或合约控制的资金路径，不是创建者个人钱包，不能随意转走。资金的具体用途和创建者的权限，取决于 Agent 合约和 Executor 权限设计。
