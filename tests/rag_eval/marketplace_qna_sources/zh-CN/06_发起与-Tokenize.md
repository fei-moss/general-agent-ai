## 六、发起／Tokenize

**Q：发起一个 agent 并在链上 Tokenize 具体是什么意思？别人 Mint 进来的是什么、用来干嘛？**

创建者把有交易能力和策略的 AI Agent 发布到市场，用户通过 Mint 份额参与它。汇入的代币用于 Agent 的真实交易，Agent 交易赚到的收益，通过 Mint / Redeem 的价格变动分给持有人。

**Q：创建者怎么赚钱？Management Fee 和 Profit Share 分别是什么、能设多少、什么时候到账？**

创建者的收益主要来源于 **Agent 费用机制**，当前主要有两类：

- Management Fee：按配置收取的 Mint Fee 和 Redeem Fee。
- Profit Share：支持该功能时，按合约分享实际交易利润。

费率、合约上限、是否支持以及到账方式都由具体 Agent 决定；应从 Agent 管理页和链上规则确认实际值及是否需要创建者主动 claim。

**Q：我发起 agent 需要自己出本金吗？还是全靠别人 mint 进来的钱？**

Agent 的主要资金由其他参与者 Mint 提供，创建者不需要自己填满资金池。创建者仍需承担部署 gas 和配置成本；没有参与者时策略规模可能受限，具体模板也可能按自身规则要求初始代币或最低启动规模。

**Q：别人 mint 进来的代币，我作为创建者能动吗？**

不能。这些代币进入的是代码托管的 Agent 合约，而不是创建者的个人钱包，因此不能像余额一样随意转走。 Agent 运行中的角色分工是：

- Minter：Mint 代币，获得份额。

- Agent 合约：负责份额记账、Mint / Redeem、净值计算和池中代币约束。

- 创建者 / Owner：负责管理 Agent（配置 executor、暂停操作、维护等）。

- Executor：负责实际执行交易或策略。

因此，创建者的身份本质是"管理员"，并不能随意支配这些代币，代币能否用于交易、能否转入外部协议、能否提费、能否暂停，都由合约规则和 executor 权限决定。

**Q: 我的策略/ prompt 会被公开吗？会不会被别人抄走？**

不会完整公开。 页面只展示你主动填写的公开描述，以及你选择上报的交易日志 / 活动记录。透明度由你自己把控：

- 完全不公开策略细节 → 参与者只能看链上数据，信任成本高。

- 适度上报交易日志 / 策略解释 → 参与者更容易理解 Agent，信任度更高。

- 公开完整 prompt / 核心策略 → 最透明，但也可能被复制。

建议你做平衡：可以公开策略方向、风控逻辑、交易记录、复盘说明；不要公开私钥、API Key、完整核心 prompt、完整系统细节。日志上报不是必须的，但能帮你建立参与者信任。

**Q: agent 上架后表现不好，我能下架/ 停掉/ 改策略吗？对持有人有什么影响？**

Agent的交易策略创建者可以随时修改，这个本质上和协议市场平台无关。目前 Moss Agent Marketplace 暂时不支持下架 Agent。

**Q：模板/链选好之后还能修改吗？**

选定模板或区块链后不会立即锁死。可以。在 Agent 未创建完成前，都支持重新选择或修改。创建完成才是所选模板和所选链不可再改的边界。

**Q：代币化并募集完成后，策略与参数是不是不能随时调整？对已经 Mint 份额的持有者有什么影响？**

代币化并募集完成后的策略边界没有变化。Agent 的交易策略你可以随时修改，这本质上不会影响 Moss Agent Marketplace 上线的 Agent。这一持有者影响结论不表示所有合约参数都等同于可编辑的交易策略。

**Q：Tokenize 上架后，我这个创建者对这些代币还有多大控制权？哪些能动、哪些动不了？**

别人 Mint 进来的代币进入的是 Agent 合约或合约控制的路径，不是创建者个人钱包，不能随意转走。这些代币的具体用途和创建者的权限，取决于 Agent 合约和 Executor 权限设计。
