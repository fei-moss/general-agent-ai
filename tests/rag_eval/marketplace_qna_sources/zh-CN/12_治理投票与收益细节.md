## 治理投票与收益细节

Governance 产品域统一使用 Agent Type `ballot`。下列问答是稳定平台机制：投票权来自提案创建时的持仓快照，投票是链上操作需要支付 gas，奖励在赎回时一并领取。具体项目、代币、固定 APY 数值、锁定期长度等属于当前 Agent 动态事实，必须读取当前 Agent context，不得用示例值补齐。

### 投票与快照

**Q：我的投票权是怎么算的？**

按提案创建时的持仓快照计算，不是按你投票那一刻的持仓。

提案页面会显示快照时间，例如 `Your voting power: 0 votes (snapshot 2026-07-20 11:33)`。你在那个时间点持有多少份额，就有多少票。

**Q：提案已经开始了，我现在 Mint 还能投这个提案吗？**

不能。快照在提案创建时就已经固定，之后的持仓变化不影响本次提案的投票权。

你可以参与在你拿到份额之后创建的新提案。

**Q：页面显示我有 0 票，提示这个提案的快照没有记录到我的持仓，是什么意思？**

说明快照时间早于你获得份额的时间。

常见情况是提案创建时你还没有 Mint，或者刚 Mint 完还没领取份额。检查提案页显示的快照时间和你的持仓时间即可确认。

**Q：临时买入大量份额可以左右投票结果吗？**

不能。投票权取自提案创建时的快照，提案发布之后再增持不产生任何投票权。

**Q：一个提案有哪些投票选项？**

赞成、反对、弃权三个选项。页面会实时显示三者的票数与占比、总票数、参与地址数量。

历史提案可以在 Proposal History 里查看。

**Q：投票需要付 gas 吗？**

需要，投票是链上操作，按所在网络的标准网络费支付。

### 收益与赎回

**Q：治理 Agent 的收益是怎么来的？**

按固定 APY 计息，奖励由项目方以其代币发放。具体 APY 数值和代币以当前 Agent context 为准。

**Q：奖励什么时候到账？**

在赎回时一并领取，持有期间不单独发放。

**Q：赎回流程和交易 Agent 一样吗？**

流程一致。提交 Request Redeem 之后进入处理队列，根据不同项目的设置可能存在锁定期，锁定期结束后，可在 View history 查看状态，转为可赎回后领取。

**Q：治理 Agent 的份额价格会波动吗？**

不会随交易表现波动。它按固定 APY 计息，与交易 Agent 的份额价格逻辑不同，后者跟随 Agent 管理资产变化。

**Q：治理 Agent 能替我们做什么？**
