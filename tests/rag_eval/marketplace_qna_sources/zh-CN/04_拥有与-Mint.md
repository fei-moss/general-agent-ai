## 四、拥有／Mint

**Q：mint 一份 agent 份额，最低要多少钱？有门槛吗？**

没有统一门槛，由每个 Agent 的创建者自己定义。 具体价格以 Agent 详情页显示为准。

**Q：mint 之后我的收益怎么算、怎么体现？是份额涨价还是另外发收益？**

Mint 后你会获得按比例代表 Agent 权益的链上份额，份额保留在你自己的钱包中。参与者带入的 Accept Token 进入 Agent 合约，可由 executor 按 Agent 策略使用；份额记账、资产托管、Mint 和 Redeem 由合约规则约束，创建者不能随意处置池中本金。收益体现在持有的份额涨价上，并不会额外发放收益。份额还是那么多份，但每份能换回的钱变多了，涨的这部分就是你的收益。

**Q：我的收益要单独领吗？有没有 Claim Yield？**

不用单独领，也单独没有 Claim Yield 机制。 收益体现在份额涨价里，Redeem的那一刻即完成收益结算。

**Q：收益体现在 exchangeRate 上涨是什么意思？我怎么知道自己赚了多少？**

ExchangeRate 上涨意味着持有的每单位份额能换回的钱变多了。收益可以按照这个公式计算：

> 收益 =（Redeem 时的份额单价 − Mint 时的份额单价）× 持有数量

**Q：我什么时候能拿到钱？赎回（Redeem）要多久到账？有锁定期吗？**

可能有锁定期，由 Agent 创建者自己定义。对于有锁定期的情况，提交 Redeem 申请并等到锁定期结束后，资金将自动到账。

**Q：mint 用什么币支付？必须是 ETH 吗？（Accept Token 是什么）**

不只是 ETH，Moss Agent Market 支持多链，支付币种具体以 Agent 详情页为准

**Q：agent 亏了，我的本金会亏吗？会亏光吗？**

持有人通过份额价值按比例承担资产波动：Agent 盈利时份额价值可能上涨，亏损时份额价值下跌。创建者不会替持有人垫付亏损，也不保证收益。如果当前 Agent 配置明确包含 Profit Share，它只按合约从利润中产生；Agent 未披露时不能假设存在 Profit Share。Agent 份额不是保本产品，参与前应查看链上记录并根据自己的风险承受能力判断。

**Q：Supply Cap 卖光了（Sold out）我还能参与吗？后面还会增发吗？**

当前 Supply Cap 全部卖空之后，Mint 按钮将置灰并显示 Sold Out，由于目前没有额外增发机制，售罄后无法再 Mint 新的份额。如果该 Agent 份额有在二级市场流通，可以直接在二级市场购买。\[这里附上二级市场的链接\]

**Q：我 mint 的份额，价格会像币一样涨跌吗？是跟着业绩还是跟着市场情绪？**

份额价值随 Agent 管理资产（AMA）波动，与 Agent 的交易业绩直接相关，Agent 交易盈利，份额价值上涨。Agent 交易亏损，则份额价值下跌。

**Q：mint 参与收益和在 DEX 上交易份额有什么区别？我该选哪个？**

两个都可以参与：

- Mint：Agent 原始份额，单价由每个 Agent 业绩决定。

- 二级市场：在开放的二级市场买卖份额，价格由市场决定。

**Q：Mint agent 份额和直接跟单（copy trading）有什么区别？**

跟单复制另一个交易者的动作到独立账户，可能出现信号延迟、漏单或跟随者执行差。持有 Agent 份额则是持有池中 Agent 资产的按比例权益，Agent 资产变化直接反映到份额价值，不需要跟随者另行成交；Agent 战绩和份额记账可在链上验证，也不需要在本地安装跟单 skill 并全程使用本地环境 24h 不休。退出可通过有流动性时在 DEX 卖出，或按当前 Agent 配置 Redeem；Redeem 是否有锁定、结算和 Claim 要以当前配置为准，有锁定时不能说成即时退出。

**Q：一个 agent 如果表现很好，我 mint 的份额会有溢价吗？溢价从哪来？**

份额价值随 Agent 管理资产（AMA）波动。 Agent 交易盈利，份额价值就上涨，这就是价值提升的来源；反之则下跌。

**Q：Mint 的时候能防止 MEV 吗？**

**可以防止 MEV。**

首先，MEV 是指在很多链上交易里，机器人能抢在你前面下单、或者故意把价格推高再卖给你（比如常见的"抢跑""夹子"），让你买得更贵。Moss 的 Mint 用了一套设计，基本排除了这类操作。

Moss 的做法是**"先排队，再统一定价"**：

1. 你点 Mint 时，不会当场按实时价格成交，而是先提交一个申请，进入下一个结算周期排队。

2. 到点后，系统统一算出这一周期的份额价格，所有这一批的人用同一个价格成交。

**Q：为什么这样就能防 MEV？**

- 价格是一批人结算时统一算出来的，不是你点击那一瞬间的实时价格，所以机器人没法抢在你前面、也没法临时把价格推上去。

- 算价格的时候，会把还在排队、没成交的钱排除在外。就算有机器人也挤进来排队，既影响不了这一批的价格，也改变不了你的成交价，更抢不走你的份额。

**Q：Mint 会失败吗？失败的话 mint 还会收取费用吗？**

会有 Mint 失败的情况，比如审批被拒绝，但失败不会产生额外的费用。

**Q：Supply Cap 和 Total Supply 有什么区别？**

Supply Cap 是 Agent 上线 Marketplace 是约定好的固定数字，而 Total Supply 是用户 Mint 的 Agent 份额总量，是可变数字。

- Supply Cap：当前 Agent 可以发行的份额数量上限。

- Total Supply：当前 Agent 已经实际发行的份额总量。
