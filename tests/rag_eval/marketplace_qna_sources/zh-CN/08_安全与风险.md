## 八、安全＋风险

**Q：Moss 会托管我的私钥/ 资产吗？我的钱安全吗？**

你的私钥和资产始终在链上归你所有，Moss 不托管、不代签、也不会替你发起任何交易。每一次操作（Mint、Redeem 等）都需要你用自己的钱包亲自签名才能生效，没有任何人（包括 Moss）能在你不签名的情况下转移或冻结你的资产，也无法进行撤销或找回等操作。简单来讲，Moss Agent Marketplace 采用非托管设计，你的资产完全由自己掌控，请务必保管好你的钱包和助记词。

**Q：agent 会不会因为 AI 判断失误造成大额亏损？有没有风控 ／ 止损机制？**

由于 Agent 份额价值随 Agent 管理资产（AMA）波动，可能存在亏损甚至亏损数额较大的风险，请密切关注 Moss Agent 详情页面展示的具体份额价值再进行 Mint/Redeem 等操作。

**Q：万一 Moss 平台出问题/ 关停了，我链上的份额和资产还在吗？我能自己赎回吗？**

因为 Moss 不托管私钥、不代签，你的份额和 Agent 合约状态以链上为准。

即使 Moss Agent Marketplace 不可用时，你钱包里的份额不会自动消失，且Agent 合约仍在链上。理论上你仍可以通过钱包、区块浏览器、脚本或其他前端直接和合约交互。若合约支持 requestRedeem / redeem，可尝试直接走链上赎回。

但能否马上赎回，代币何时到账等问题，还要参考 Agent 链上状态，例如：

- Agent 是否暂停了 Redeem。

- 你是否已发起 redeem request。

- 赎回是否已结算为 claimable。

- 合约里流动性是否充足。

- 代币是否还部署在外部交易或协议里。

- 当前链和合约是否正常运行。

**Q：我在哪些地区/ 国家不能用？有没有地域限制？**

中国大陆暂不可用，其他地区可用。 具体请以 Moss 官方公告确认为准。

**Q：钱包的助记词丢了怎么办，Moss 能帮我找回吗？**

Moss Agent Marketplace 采用非托管设计，你的资产完全由自己掌控，请务必保管好你的钱包和助记词。

**Q：投 AI Agent 具体有哪些风险？**

由于 Agent 份额价值随 Agent 管理资产（AMA）波动，可能存在亏损甚至亏损数额较大的风险，请密切关注 Moss Agent 详情页面展示的具体份额价值再进行 Mint/Redeem 等操作。

**Q：Tool 自助建的 agent 和官方/ 模板部署的 agent，在可信度/ 风险上有区别吗？**

这是两个不同层面的东西：Tool 是策略创建与执行层，模板部署提供的是链上份额管理与 Tokenize 渠道。无论采用哪种方式，都不代表官方背书或风险保证。判断可信度与风险时，应结合链上记录、创建者披露、合约参数、历史交易表现和风控措施，而不能只看是"Tool 自建"还是"模板部署"这个标签。判断方法可参考「怎么挑 Agent（Discover）」。
