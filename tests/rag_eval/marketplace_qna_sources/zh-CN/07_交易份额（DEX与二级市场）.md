## 七、交易份额（DEX／二级市场）

**Q：我 mint 的份额怎么卖？**

Agent 详情页会检测该 Agent 份额有没有对应的 DEX 交易对：

- 有 → 将会展示 Trade on DEX 模块，卖出流程与 Uniswap 交易一致。

- 没有 → 卖出只能通过 Redeem 一种方式。

**Q：二级市场没人接盘/ 流动性差，我想卖卖不掉怎么办？**

二级市场流动性不足的情况下可以通过 Redeem 赎回此前的代币。

**Q：DEX 上的份额价格和 mint / 赎回价格（NAV）不一样，为什么？该按哪个？**

因为 DEX 价格和 Mint/赎回是两个不同来源的价格：

- 官方价（NAV / exchangeRate）：合约算出来的净值，也就是"一份份额现在实际值多少 Accept Token"。你 Mint 或 Redeem 时用的就是这个价，它也能反映 Agent 到底赚没赚钱。

- 市场价（DEX 价格）：二级市场上买卖双方谈出来的价，会被买的人多不多、流动性好不好、大家看不看好这个 Agent 等因素影响，可能跟官方定价产生一定的出入。

具体看哪个取决于你想怎么操作：

- 想直接和合约 Mint / 赎回 → 看官方价，再留意费用和结算状态。

- 想在 DEX 上买卖 → 看市场实时价，再留意流动性、滑点和手续费。

- 如果两个价差得很大，要提高警惕：可能是没什么人交易（流动性不足），也可能是市场情绪或赎回限制造成的溢价 / 折价。

Moss Agent Marketplace 不会替你判断应该选哪一种，也不提供买卖建议，请自己比较价格、手续费、等待时间和风险之后再做决定。

**Q：在 DEX 上买份额和直接 mint，更推荐哪一种？**

可以综合比较价格、能买到的数量、手续费，再决定以哪种方式获取 Agent 份额。
