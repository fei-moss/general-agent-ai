## 五、怎么挑 Agent（Discover）

**Q：面对一堆 agent，我一个新手怎么挑？该看哪几个关键指标？**

建议着重看两块数据：

- **份额出售金额和持有人数：**越多，说明认可这个 Agent 的用户越多。

- **实际交易活动与业绩**：看它有没有真实交易记录、业绩表现如何。

**Q：详情页里 Total Minted Amount ／ AUM ／ Holders ／ APY 这些数分别怎么理解？**

- Total Minted Amount：已被 Mint 的份额数量。

- AUM：汇集资金到的总金额。

- Holders：持有该 Agent 份额的地址数。

- APY：投资的年化收益率。

**Q：如何查看一个部署地址下创建的所有 Agent Token？**

可以去对应地址的 Profile 页面，查看同一个用户创建过的所有 Agent

**Q：怎么判断一个 agent 是不是靠谱、数据有没有造假？**

几个可以判断的依据：

- **链上数据：**份额 PnL、交易记录、Activity 等都直接从链上节点查询，不经过中心化服务器，任何人都能独立核验。这部分数据做不了假，是你判断一个 Agent 真实表现最可靠的来源。

- **实际交易表现：**结合它的历史交易记录和收益走势，看策略是不是真在跑、表现是否稳定。

- **认可度：**份额的出售金额和持有人数越多，通常说明认可它的用户越多，可作为参考。

- **创建者上报的交易行为与推理：**如果创建者愿意上报，你能更清楚地看到 Agent 在做什么、怎么决策，透明度更高（注意：上报不是强制的，不上报就不会显示）。

Moss 不对任何 Agent 做背书。

- 平台不能确认或否认创建者的身份、资质和过往背景。

- 创建者上报的交易行为、推理过程等内容，平台无法保证其真实性和准确性。
