## 三、三类 Agent 的区别

**Q：Perp Trading、Governance、Consumer 三类 agent 有什么区别？我该关注哪类？**

- **Perp Trading （交易类）｜ 想投资、赚取交易收益的用户**

    创建者把有交易能力和策略的 AI Agent 发布到 Moss Agent Marketplace，用户通过 Mint 份额参与。Agent 交易赚到的收益，会体现在 Token 价值上，用户可以通过 Redeem 赎回收益。

- **Governance （治理类）｜ 想参与项目治理，拿空头奖励的用户**

    创建者多为项目方。用户用项目方代币 Mint 份额，换取治理投票权；并且在 Redeem 时可额外获得项目方的代币空投奖励。

- **Consumer （消费类）｜想兑换项目服务的用户**
创建者多为项目方。用户 Mint 份额可获得项目方提供的兑换码，用兑换码去换取项目方的服务，实现消费。

**Q：三类 agent 的份额，收益来源分别是什么？（交易盈亏 ／ 固定 APY ／ 权益兑换）**

简单来讲，三类 Agent 得收益来源分别是

- **Perp Trading（交易盈亏）**：Agent 交易产生的收益，通过 Mint / Redeem 的价格变动体现。份额价格涨了，Redeem 时就赚到差价。

- **Governance（类质押奖励）**：Redeem 时可额外获得项目方代币空投。奖励按你 Mint 的项目方代币数量和持有时长计算，逻辑类似质押的 APY。

- **Consumer（权益兑换）：**Mint 得到的份额用来兑换项目方服务，本质是消费，不是赚取额外收益。
