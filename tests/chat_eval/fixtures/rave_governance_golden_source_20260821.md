# Ask This Agent｜Rave Governance Agent(owner 提供,2026-08-21)

Q：这个 agent 是做什么的？ 
A：把 $RAVE 铸造成 vRAVE 份额，持有期间可以参与 RaveDAO 的治理投票，同时按 6% 的固定年化累积 $RAVE 奖励。奖励在赎回时一并领取。
Q：vRAVE 是什么？ 
A：这个 agent 的份额代币，由 $RAVE 铸造而来。持有它意味着你有 RaveDAO 的投票权，以及累积中的 $RAVE 奖励。
Q：和直接持有 $RAVE 有什么区别？
A：直接持有 $RAVE 不会累积奖励，也不通过这个 agent 参与投票。铸造成 vRAVE 之后，两样都有,代价是资金进入合约，赎回需要走两步流程。
Q：这是投资产品吗？ 
A：不是。它是一个治理参与工具。6% 是 RaveDAO 提供的固定激励，不是投资回报。
Q：这是 RaveDAO 发的吗？ 
A：这是 Moss Agent Marketplace 与 RaveDAO 合作发行的治理类 agent。6% 的奖励由 RaveDAO 提供。
Q：怎么开始？ 
A：连接钱包，输入你要铸造的 $RAVE 金额，提交申请。结算完成后 vRAVE 份额变为可领取，领取后就出现在你的持仓里。
Q：最少要 mint 多少？ 
A：没有最低门槛。任意金额的 $RAVE 都可以参与投票。
Q：有上限吗？ 
A：有。单账户上限 50,000 $RAVE。
Q：为什么设上限？ 
A：防止单个地址在治理中占据过大权重。
Q：mint 之后马上能投票吗？ 
A：需要等份额结算完成并领取之后。
Q：mint 要收费吗？ 
A：【Mint fee】。费率在确认之前会显示在页面上。
Q：可以用别的币 mint 吗？ 
A：不可以。这个 agent 只接受 $RAVE，这是合约层面固定的。
Q：可以分多次 mint 吗？ 
A：可以，累计不超过 50,000 $RAVE 上限即可。
Q：怎么投票？ 
A：持有 vRAVE 之后，在【投票入口】参与 RaveDAO 的提案投票。
Q：投票权怎么算？ 
A：按你持有的 vRAVE 数量计算。
Q：一个提案怎么才算通过？ 
A：赞成票占总票数的 50% 以上即通过。
Q：我可以投任意金额都能投票吗？ 
A：可以。只要你持有 vRAVE 就有投票权，只是权重按持仓数量计算。
Q：不投票会怎样？ 
A：不影响你的 6% 奖励累积。投票是权利，不是义务。
Q：投票是我自己投，还是 agent 替我投？ 
A：由你自己投。 这个 agent 提供的是投票资格和奖励累积，不代替你做决定。
Q：我在投票之后可以赎回吗？ 
A：可以
Q：投票有截止时间吗？ 
A：【按每个提案的设置，以提案页显示为准】
Q：6% 是什么意思？ 
A：这是 RaveDAO 提供的固定年化奖励，以 $RAVE 计价，按你持有 vRAVE 的时长和数量累积。
Q：6% 会变吗？ 
A：这是固定的，对已进场的持有人不会更改。
Q：奖励什么时候到手？ 
A：在你赎回的时候，与本金一并发放。 持有期间它是累积状态，不会单独发到你钱包。
Q：中途赎回，已累积的奖励还有吗？ 
A：【按实际规则填】
Q：为什么不能随时提取奖励？ 
A：奖励设计为在赎回时一并结算，这样计算口径统一，也避免频繁的小额发放。
Q：这算是理财产品吗？ 
A：不算。6% 是 RaveDAO 为鼓励治理参与提供的固定激励，不涉及任何投资运作。
Q：钻石有什么用？ 
A：Moss 生态内的积分，用于未来空投权益或平台内消费。
Q：钻石和 6% 奖励冲突吗？ 
A：不冲突，两者独立发放。钻石由 Moss 提供，6% 由 RaveDAO 提供。
Q：怎么把 $RAVE 拿回来？ 
A：在 Redeem 页面提交赎回申请，结算完成后本金与累积的奖励一并领取。
Q：有锁定期吗？ 
A：【按实际规则填】
Q：赎回也要等吗？ 
A：【按实际规则填】
Q：赎回之后投票权还在吗？
 A：不在。赎回意味着 vRAVE 被销毁，投票权随之结束。
Q：可以只赎回一部分吗？ 
A：【按实际规则填】
Q：赎回要收费吗？ 
A：【Redeem fee】，费率在确认前会显示。
Q：我的 $RAVE 在谁那里？ 
A：在智能合约里。不在 RaveDAO 手上，也不在 Moss 手上。
Q：规则会不会中途改？ 
A：6% 的奖励率、上限、赎回条款这些，对已经进场的用户不会改变。
Q：我怎么验证？ 
A：合约地址和所有交易记录都在链上，可以自行查看。
Q：vRAVE 可以转给别人吗？ 
A：不可转让，只能通过赎回领取。
Q：vRAVE 会涨价吗？ 
A：vRAVE 对应的是你存入的 $RAVE 加上累积的奖励。它不是一个价格波动型资产。
Q：6% 是浮动的吗？ 
A：不是，是固定的。
Q：我可以一边投票一边把钱拿回来吗？ 
A：赎回之后份额被销毁，投票权同时结束。两者不能同时保留。
Q：这是保本的吗？ 
A：赎回时你拿回的是你存入的 $RAVE 加上累积的 6% 奖励，以 $RAVE 计价。$RAVE 本身的价格波动不在这个机制的保障范围内。
