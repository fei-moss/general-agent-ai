# Redemption / PixVerse Agent Golden Cases(owner 提供,2026-08-19)

第一部分：通用 Redemption Agent
Q：这个 agent 是做什么的？ 
A：它让你把资金放进合约来换取【品牌方】的权益。你 mint 份额，持有到门槛之后可以主动兑换成兑换码，用码去【品牌方】使用对应的服务。如果不想要了，也可以退回本金。
Q：和直接在【品牌方】官网买有什么区别？ 
A：直接买的话，钱在付款那一刻就归对方了。在这里，钱进入的是合约，在你真正兑换成码之前，你随时可以取回。
Q：这是投资产品吗？ 
A：不是。这是一个换取权益的工具。份额的价值不来自升值预期，来自你能用它兑换什么。
Q：这是 NFT 吗？ 
A：不是。份额是标准的 ERC-20 代币，可分割，不是唯一的收藏品。
Q：我需要懂加密货币才能用吗？ 
A：需要一个钱包和对应的结算代币。除此之外的流程和买点数包差不多：放钱、拿份额、要用的时候换码。
Q：怎么开始？
 ：连接钱包，在 Mint 区输入金额，提交申请。结算完成后份额会变为可领取，领取后就出现在 My Shares 里。
Q：最少要 mint 多少？
A：【最低金额】。但要注意，兑换码需要达到【Threshold】份额才能换一个，低于这个数量的份额可以持有，也可以赎回，但换不了码。
Q：mint 之后马上有兑换码吗？ 
A：没有。mint 只给你份额。兑换码需要你自己去 My Shares 里主动兑换。
Q：mint 要收费吗？ 
A：【Mint fee】。费率在你确认之前会显示在页面上。
Q：mint 用什么币？ 
A：【Accept Token】。这个是该 agent 部署时就固定的，不能更改。
Q：可以用别的币吗？ 
A：不可以。每个 agent 只接受一种结算代币，这是合约层面固定的。
Q：怎么拿到兑换码？ 
A：在右侧 “我的份额” 模块点「去兑换」，在弹窗里选择数量，确认之后就会生成兑换码，可以直接复制。
Q：多少份额换一个码？ 
A：【Threshold】份额换一个。
Q：兑换会消耗我的份额吗？ 
A：会。 兑换成功后对应的份额会被回收，你不再持有那部分。
Q：我可以只兑换一部分吗？ 
A：可以。你可以选择兑换数量，没兑换的份额继续持有，也可以之后再兑换或者 Refund。

A：【按品牌方规则填】。这个由【品牌方】设定，请以兑换页显示的为准。
Q：兑换码怎么用？
A：兑换成功后弹窗里有「去消费」的跳转按钮，会带你到【品牌方】的使用入口。
Q：兑换失败了怎么办？
A：如果份额已扣但码没生成，系统会记录异常并重试。这种情况请联系官方支持，不会让你损失份额。
Q：怎么把钱拿回来？
A：未兑换的份额可以选择赎回，对应的本金退回给你。
Q：所有份额都能赎回吗？ 
A：只有未兑换的份额可以。已经换成兑换码的那部分份额已经被回收，无法再赎回。

Q：赎回需要等吗？ 
A：是的，提交申请 → Pending → Claimable → 领取。
Q：赎回有次数限制吗？ 
A：没有。你可以分多次赎回。
Q：我的钱在谁那里？ 
A：在智能合约里。不在【品牌方】手上，也不在 Moss 手上。
Q：【品牌方】能动我的钱吗？ 
A：不能。合约限制了这一点，他们可以运营这个 agent，但碰不到你的本金。
Q：Moss 能动我的钱吗？ 
A：不能。同样受合约限制。
Q：规则会不会中途改？ 
A：门槛、费率这些条款对已经进场的用户不会改变。合约不提供这个操作，对【品牌方】不提供，对我们也不提供。
Q：如果【品牌方】倒闭了会怎样？ 
A：你的本金仍然在合约里，赎回不受影响。但兑换码的使用需要【品牌方】的服务存在，这部分依赖于他们的履约。
Q：份额可以转给别人或在交易所卖掉吗？ 
A：份额是标准 ERC-20，具备流通条件。目前 Moss 上的退出方式是 Refund。
Q：份额会涨价吗？ 
A：份额的价值由合约的兑换率决定。这个 agent 的设计目的是兑换权益，不是价格波动。

A：你当前持有的、还没有兑换的份额数量。已经换成码的部分不会出现在这里。
Q：铸造活动/ 兑换码活动里能看到什么？ 
A：铸造活动显示铸造 agent 份额的操作记录，兑换码活动显示兑换码的生成记录。地址都做了脱敏。
Q：为什么按钮是灰的？ 
A：可能是你还没持有份额，或者该 agent 被暂停了。暂停时会显示提示。
Q：显示 Paused by owner 是什么意思？ 
A：发行方暂停了铸造和赎回。你已持有的份额不受影响。
Q：我可以一边拿兑换码一边把钱退回来吗？
A：不可以。兑换会消耗份额，被消耗的份额无法再赎回。 你需要在两者之间做选择。
Q：我持有久了会自动收到兑换码吗？ 
A：不会。兑换需要你主动发起。
Q：这是保本的吗？ 
A：赎回拿回的是份额在当时对应的实际价值，扣除费用。不是一个固定金额的承诺。
Q：这个有年化收益吗？ 
A：没有。这不是一个收益产品，它的用途是兑换权益。
Q：出问题找谁？ 
A：【官方支持渠道】。涉及兑换码使用问题，请联系【品牌方】的客服；涉及铸造、赎回、份额问题，请联系 Moss。
Q：我有个问题这里没有答案。 
A：可以到【官方社群链接】提问，或联系【支持邮箱】。

第二部分：PixVerse Agent 专属
一、关于 PixVerse
Q：PixVerse 是什么？ 
A：一家 AI 视频生成公司，做自研的视频基础模型。产品包括文生视频、图生视频、Agent 对话式创作、Marketing Hub、Canvas 工作流和 CLI。
Q：它的模型好吗？ 
A：截至 2026 年 4 月 2 日，PixVerse V6 在 Artificial Analysis 的 image-to-video 榜单上排第一，ELO 1,343，价格 $4.80/分钟。同一榜单上 VEO 3.1 是 ELO 1,246、$24.00/分钟，Sora 2 Pro 是 1,195.5、$18.00/分钟。榜单会更新，建议以最新为准。
Q：为什么选 PixVerse 合作？ 
A：因为这个模式最有说服力的地方，是用在一个你本来就想买的东西上。PixVerse 服务 177 个国家，模型跑在 Freepik、fal、Replicate 等产品后面。
Q：PixVerse 是加密项目吗？ 
A：不是。它是一家 AI 公司，靠模型本身在竞争。这次是它选择用链上结算给用户提供一种新的付费方式。

三、边界
Q：Moss 和 PixVerse 是什么关系？ 
A：合作关系。PixVerse 提供权益，Moss 提供发行和结算的基础设施。你的本金由合约保管，双方都碰不到。
Q：PixVerse 能看到我的钱包吗？ 
A：兑换码的发放需要把码和你的地址对应起来。除此之外的信息不涉及。
Q：PixVerse 停止支持这个合作了怎么办？ 
A：你的本金在合约里，赎回不受影响。已生成的兑换码的使用，取决于 PixVerse 的服务条款。
Q：这是 PixVerse 发币吗？ 
A：不是。这里没有 PixVerse 的代币。你 mint 的是这个 agent 的份额，用途是兑换 PixVerse 的权益。
Q：份额和 PixVerse 公司有关系吗？
A：没有。份额代表的是可以兑换的权益，和公司的股权、估值都没有关系。
